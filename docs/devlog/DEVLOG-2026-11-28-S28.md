### What Was Built
`Matrix.Preflight(tools, kubernetesVersion, installed)` returns findings for the stack as it will be after the plan: each target's `min_kubernetes` against the cluster, and `incompatible_with` in both directions (a target's entry against the other tools, and the entries of installed tools the plan leaves alone against each target). Names go through `CanonicalName`, so aliases work on both sides.

The reconciler runs it in `Pending`, before the approval gate, so a person sees a blocker before approving. It writes a `PreflightPassed` condition with reason `Passed`, `PassedWithWarnings`, `PreflightBlocked` or `PreflightUnavailable`. A blocked plan stays `Pending` (Ready reason `PreflightBlocked`) and is checked again after 5 minutes (`preflightRetry`).

### Key Decisions
- **A cluster below `min_kubernetes` warns, it does not block.** Since S26 the field is the oldest Kubernetes upstream supports or tests, which is stricter than the chart's `kubeVersion`; blocking would stop upgrades that work. One constant, `planner.MinKubernetesSeverity`, makes it a block. Owner may revisit.
- **`incompatible_with` blocks.** It records a conflict upstream names.
- **Partial versions name a line.** A listed `1` matches every 1.x, `1.14` every 1.14.x, `1.14.2` that release only. A version that does not parse never matches.
- **Fail closed for the stack, fail open for the version.** If the installed stack cannot be read, the plan waits (`PreflightUnavailable`), because it feeds the blocking check. If only the cluster version cannot be read, the plan gets a warning and the floor is skipped.
- A tool with no known installed version is not checked; a conflict between two tools the plan does not touch is not blamed on the plan.
- No `incompatible_with` data ships today (S26 removed all unsourced pairs), so the block path is exercised by tests only.

Reconciler үүнийг `Pending` үед, зөвшөөрлийн өмнө ажиллуулдаг. `PreflightPassed` condition-д `Passed`, `PassedWithWarnings`, `PreflightBlocked`, `PreflightUnavailable` шалтгаануудын аль нэгийг бичнэ. Блоклогдсон төлөвлөгөө `Pending`-д үлдэж, 5 минутын дараа дахин шалгагдана.

- **`incompatible_with` блоклоно.**
- **Хэсэгчилсэн хувилбар нь шугамыг заана:** `1` нь бүх 1.x, `1.14` нь бүх 1.14.x, `1.14.2` нь зөвхөн тэр хувилбар. Задлагдахгүй хувилбар хэзээ ч таарахгүй.
