## What Was Built

### matrix.go additions

**`RiskAtOrBelow(risk, ceiling ai.RiskLevel) bool`** — package-level function using a `riskOrder` map for ordering `LOW < MEDIUM < HIGH < BLOCKING`. Returns true when risk ≤ ceiling by numeric rank.

**`ListTools() []string`** — returns all tool names from the matrix, sorted alphabetically for deterministic output.

**`LatestSafeVersion(tool, currentVersion string, tolerance ai.RiskLevel) (string, ai.RiskLevel, bool)`** — iterates all KB versions newer than `currentVersion` (via `CompareMinor`), keeps those whose `risk_level` (uppercased for normalisation from YAML lowercase) is at or below `tolerance`, returns the highest qualifying version.

**`DetectionSpec` / `DeploymentMatchSpec`** — mirror the `detection:` block in tool YAML files. Added `Detection DetectionSpec` field to `ToolCompatibility` so `Load` parses detection rules automatically. **`Detections() map[string]DetectionSpec`** exposes them for conversion in `main.go`.

### CompatibilityPolicy CRD extensions

- **`AutoplanConfig`**: `Enabled bool`, `MaxRisk ai.RiskLevel` (`+kubebuilder:default=LOW`), `AutoApprove bool`
- **`TrackedToolStatus`**: per-tool status with `Installed`, `InstalledVersion`, `Source`, `Namespace`, `RecommendedVersion`, `UpgradeAvailable`, `Risk`, `Message`
- **Spec**: `TrackedTools []string` (empty = discovery mode), `Autoplan *AutoplanConfig`
- **Status**: replaces the empty comment stub with `LastScanTime`, `Mode`, `Tools`, `UntrackableTools`, `UnknownInstalled`

### Reconciler rewrite (5-step model)

1. **Mode determination** — `TrackedTools` empty → discovery (all KB tools); non-empty → focused (listed tools only, unknowns go to `UntrackableTools`)
2. **Single scan pass** — `ClusterScanner.ScanAll` + optional `WorkloadScanner.ScanWorkloads`; merged into `installed` map with helm/flux/argocd overwriting raw entries
3. **TrackedToolStatus build** — for each evaluated tool: not installed → message "not currently installed"; installed + upgrade found → `UpgradeAvailable=true` with `RecommendedVersion` and `Risk`; installed + up to date → message "up to date". `UnknownInstalled` collects installed tools with no KB entry.
4. **Push gate** — `StackUpgrade` created only when `Autoplan.Enabled=true` AND `RiskAtOrBelow(ts.Risk, MaxRisk)` AND no existing StackUpgrade with the same sanitized name. `AutoApprove=true` sets `status.Phase=Approved` via a second `Status().Update()` call after create.
5. **Status persist** — `LastScanTime=now`, `Status().Update()`; requeueAfter `ScanInterval` (default 5 min).

## Key Decisions

1. **KB risk levels are lowercase, `ai.RiskLevel` constants are uppercase** — `LatestSafeVersion` normalises via `strings.ToUpper(v.RiskLevel)` when building `entryRisk`. This keeps KB YAML human-friendly and avoids forcing uppercase in the YAML files.

2. **Two separate risk gates** — `policy.Spec.RiskTolerance` controls which upgrades are surfaced in status (pull); `Autoplan.MaxRisk` controls which surfaced upgrades get a StackUpgrade created (push). Default for `RiskTolerance` when unset: `ai.RiskHigh` (show all non-blocking). Default for `MaxRisk` when unset: `ai.RiskLow` (only create low-risk upgrades automatically).

3. **Prefer non-raw source** — when a tool is found by both `WorkloadScanner` (raw/kubectl-apply) and `ClusterScanner` (helm/flux/argocd), the non-raw entry wins in the installed map. Helm-managed tools are upgradeable via the executor; raw installs are not.

4. **Detection parsing stays in `planner`; conversion to `scanner.ToolDetection` done in `main.go`** — avoids creating an import cycle between `planner` and `scanner`. Both packages remain independent.

5. **`sanitizeName` preserves `.`** — DNS subdomain names (RFC 1123) allow dots, so `auto-cert-manager-1.14` is valid. Only non-[a-z0-9-.] characters are replaced with hyphens.
