### Key Decisions
1. **Rebuild from sources, not patch the old entries.** Most of the old claims had no source, so every
   entry was written from an upstream document, and the old text was not kept.
2. **One entry per minor, up to today.** The chain is continuous, so multi-hop paths (S31) have an entry
   for every step. Where a tool's releases don't map onto minors, the file states its own rule:
   - prometheus-stack: one entry per operator minor;
   - vault: one entry per vault-helm release that changes the Vault version.
3. **The entry is the patch upstream says to install.** Recommendations never point at a release
   upstream warns against. `Resolve("1.14.0")` failing is intended.
4. **`min_kubernetes` = upstream's supported or tested floor, never below the chart's `kubeVersion`.**
   The charts' floors are loose (cert-manager says ≥1.22 for every release since 1.12). Upstream's
   floor is what a safety-first pre-flight check needs. Whether S28 blocks or warns below it is S28's
   call.
5. **Unsourced `incompatible_with` removed, not kept.** A false incompatibility would block valid
   upgrades once S28 enforces the field. `Resolve` still returns the field (synthetic test).
6. **No ingress-nginx entry.** It was retired upstream (repository archived March 2026; last releases
   controller v1.15.1, v1.14.5 and v1.13.9). The KB cannot recommend upgrades for a retired project.
   Its sourced conflict lives in cert-manager 1.18's notes.
7. **`LatestSafeVersion` semantics unchanged.** Only the target entry's risk counts, so Argo CD 2.8 →
   3.5 reads MEDIUM across 3.0's HIGH. Changing that belongs to multi-hop paths (S31), so a test pins
   today's behaviour and the todo carries it.
8. **Version 0.2.0 as a literal.** The tagged build must not report 0.1.0. Build-time injection goes
   with goreleaser (S48–51).
9. **v0.2.0 tag: the S26 merge commit on `main`.** The v0.2.0 exit criteria are met:
   - every KB tool is detected with the right name and version across Helm, Flux v2 (S24), Argo CD
     (this session) and raw installs;
   - the KB entries carry source links and pass a validation test.
