### What Was Built
**Repo hygiene.** The scratch file and the root binary are gone from HEAD. Both still exist in git
history (commits `532fa4b`, `74ae838`); purging them requires a history rewrite and force push,
which was deliberately not done without the owner's explicit go-ahead.

**Build.** `make help` lists targets. `make verify` (vet + test + build) is the pre-commit gate.
`make generate` regenerates deepcopy, CRDs and RBAC using controller-gen v0.21.0 run through
`go run sigs.k8s.io/controller-tools/cmd/controller-gen@v0.21.0`, so it works identically on Windows,
Linux and CI with no GOPATH install and no go.mod churn. Regenerated CRDs and deepcopy are
byte-identical to what was committed; `config/rbac/role.yaml` is now generated. `make build` no
longer fails on the missing `cmd/cli`. `make run` passes `--knowledge-base-path=knowledge/tools` —
the default `/etc/viltrumite/knowledge` never existed on a dev machine, so `make run` could not have
worked locally before. `make ui` runs `npm ci && npm run build`.

**License and README.** Apache-2.0, the Kubernetes-ecosystem default. The README is deliberately
honest about maturity: execution is marked experimental and AI wiring as partial.

**Workflow.** One roadmap session = one fresh Claude Code session = one `session/<N>-<topic>`
branch = one PR. End of session: code review → `/commit` (gated by `make verify`) → `/update-docs`
(bilingual devlog) → todo sync → push + PR → a spawn-task chip that starts the next session in a
fresh context. `docs/HANDOFF.md` is now the first thing each session reads.

### Errors Hit
1. **controller-gen missing** — `$(shell go env GOPATH)/bin/controller-gen` did not exist. Fixed by running it through `go run ...@version`.
2. **Windows path colon** — `output:crd:artifacts:config=C:/...` broke controller-gen's argument parser (`:` is its separator). Only relative output paths are used; the Makefile already does that.
3. **`go get controller-tools@v0.21.0` dragged k8s.io 0.35 → 0.36** while controller-runtime stays at v0.23 (built for 0.35). Reverted go.mod/go.sum and switched to `go run pkg@version`, which runs outside the module.
4. **`go mod tidy -diff` reported 1,110 changed lines** — a CRLF artifact of `core.autocrlf=true` (index is LF, working tree CRLF). The real diff is 22 lines.
5. **`make build` failed** on `./cmd/cli/...` (directory does not exist). Removed from `build`; the `vilt` plugin lands in v0.9.0.
6. **`gh` CLI is not installed** on this machine. The PR step falls back to pushing the branch and opening the GitHub compare URL (CLAUDE.md Step 5).

### Key Decisions
1. **controller-gen via `go run pkg@version`**, not a tools.go/go.mod pin. Pinning v0.21.0 in go.mod forces k8s.io 0.36 onto controller-runtime v0.23. Running it outside the module keeps the operator's dependency graph untouched.
2. **Remove from HEAD only.** A history rewrite changes every commit hash and needs a force push; that is the owner's call. Recorded in HANDOFF.md.
3. **Apache-2.0** as the license — standard for Kubernetes operators; can still change before v0.1.0.
4. **Devlog file per session: `DEVLOG-YYYY-MM-DD-S<N>.md`.** With one session per Claude session, two sessions can land on the same day; the date-only name would force stacking, which CLAUDE.md forbids. One file holds both languages, so "one session = one file" still holds.
5. **Verbatim output only in the English half** of each devlog; the Mongolian half summarizes it. This avoids duplicating long logs.
6. **Roadmap reorder.** The old sessions 20–22 (dashboard, Plan upgrade, raw guard) move to S34, S35, S29. Building UI on top of wrong detection data would mean redoing it after v0.2.0.
7. **Track `ui/package-lock.json`** for reproducible `npm ci` builds (needed by the S21 Dockerfile).
